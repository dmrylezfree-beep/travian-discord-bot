# Учёт пуша

Группа -1002493230303, ветка 21472. Владелец 317595036.
Добавьте @Push_travian_bot в группу администратором, затем на VPS запустите
`/usr/local/bin/travian-push-setup`. Ввод токена скрыт, сохраняется только
в /etc/travian-push-token.env с правами 600. Не передавайте токен в чат.

Меню открывается командой /push@Push_travian_bot в нужной ветке.
Только владелец создаёт и завершает заявки. Он выбирает игровой аккаунт
из Сокола или Fun Е, связывает с Telegram ID получателя (либо /recipient
ответом на сообщение получателя в этой ветке), затем вводит норму.
Норма — сумма всех типов ресурсов с одного игрового аккаунта.
Ввод нормы сразу создаёт заявку.

Получатель выбирает аккаунт отправителя и отмечает меньше нормы, норму
или выше нормы. Отметку можно заменить или сбросить. Учёт виден всей группе.
Отсутствие отметки не доказывает, что ресурсы не отправлены.
Состав фиксируется по снимку мира при создании, получатель исключается
из отправителей. Учитываются аккаунты, а не деревни.

SQLite с журналом изменений: /var/lib/travian-push/ledger.sqlite.
При копировании работающей базы используйте SQLite backup API.
Код обновляется через штатный GitHub → VPS updater; в процессе настройки
перезапускается только новая служба travian-push.service.
